## ✨ About

Mari's Calendar is a lightweight desktop application designed with a soft and elegant interface.  
Built using Electron, it focuses on simplicity, usability, and aesthetic design.

---

## 🌿 Features

- Custom frameless window
- Minimal UI design
- Desktop executable (.exe)
- Custom icon
- Close button with IPC communication

---

## 🛠 Built With

- Electron
- HTML
- CSS
- JavaScript
